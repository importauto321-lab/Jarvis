# Hermes
Wired in: yes, on the iMac, from the computer and the iPad. Always-on (stays awake) and a browser test on example.com done. Gmail, Calendar, Drive and the business sites are not connected.

## Does well
- Working with files and folders on the iMac.
- Running commands on the iMac.
- Doing work in its own web browser.
- Being the always-on worker: the iMac stays awake and Hermes reopens itself.

## Rules
- One yes per job for ordinary browser work, then Hermes finishes it on any website it needs; steps that look like sending, paying, deleting, posting or signing in still ask on their own.
- Ask the user before Hermes sends, pays, deletes or posts anything, or logs into a new account. This is judged from the words in each browser step, so it can miss one.
- Do not touch Super Dispatch, Central Dispatch or Trucking Office until the user says so. The gate refuses any request that mentions them; opening them needs a code change.
- Commands, file changes and other actions still need their own yes, from the iPad or the computer.
- Add one power at a time, test each for real on the iMac, and show proof.
- No cards or banking logins in its browser.
