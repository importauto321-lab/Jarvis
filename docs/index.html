    Gemini: web search, videos, documents, pictures

    A Google Gemini API key lets Jarvis search the live web for current rates, news and prices, watch YouTube videos you link, read documents, PDFs, pictures and audio you attach, and read long email threads. It's saved only in this browser on this device. Get one at aistudio.google.com.

    Location

    Hermes (your computer)

    Just talk to Jarvis: when a job needs your computer, he sends it to Hermes there and tells you the result. (You can still say "ask Hermes to...".) If email, calendar or web text is part of the conversation, he asks before sending a job. This device needs Tailscale on, and the computer must be awake with Hermes open. With the ask-first gate installed on that computer, Hermes waits before it deletes, sends, pays or changes anything, and Jarvis shows you the request to tap Yes or No. It is a safety net, not a guarantee. Hermes can run commands on that computer, so treat its key like a password.
